How the value is built. Implied value = TVL × 0.42 × growth × age × chains × category. Growth uses the 7-day TVL change (clamped −30%…+100%); age is days listed with no token (capped at 1,500 days); chains is 1 + 0.08·ln(1 + chain count); category discounts venues unlikely to need a token (CEX 0.70, bridges 0.80) and favours money markets and exchanges (1.10). Every factor is shown on each protocol's detail view.
